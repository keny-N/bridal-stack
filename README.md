# Bridal Stack - 結婚式BGMセットリスト共有アプリ

結婚式のゲスト向けに、BGMセットリストと選曲に込めた新郎新婦の想いを共有するためのWebアプリケーションです。

## 🌟 特徴

- **仕様書駆動開発 (cc-sdd)**: `.kiro/specs` 配下の仕様書に基づき、厳格なプロセスで開発されています。
- **ももクロ選曲**: すべての楽曲に「ももいろクローバーZ」の楽曲を採用し、各シーンに合わせたメッセージを掲載。
- **ネタバレ防止機能**: 演出のワクワク感を損なわないよう、確認ダイアログに同意するまで曲名を表示しない仕組み。
- **モバイルファースト**: 会場での閲覧を想定した、シンプルで直感的なUI。

## 🛠 技術スタック

- **Frontend**: Next.js (App Router), TypeScript
- **Styling**: Vanilla CSS (CSS Modules)
- **Deployment**: Static Site Generation (SSG)

## 📁 プロジェクト構造

- `src/app`: 各画面のルーティングとレイアウト
- `src/components`: UIコンポーネント
- `public/data/setlist.json`: セットリストのデータソース
- `.kiro/specs`: 要件定義、設計、タスク管理ドキュメント

## 🚀 開発の背景

エンジニアとして、自分たちの結婚披露宴をより楽しんでもらうために開発しました。どのようにコードが書かれ、どのような設計プロセスを経て実装されたかを公開することで、同じような志を持つエンジニアの参考になれば幸いです。
